# 🐉 Operation Hydra — Unraveling a Multi-Vector Cyber Crime

**Assignment 2 – Unit 2: Types of Cyber Crimes**
A simulated, end-to-end investigation of a multi-stage cyber-crime campaign combining
**phishing → web/email spoofing → malware injection → financial fraud**, analysed with both
technical and legal approaches.

> ⚠️ **Ethics disclaimer:** Every artefact in this repository is **synthetic**. The e-mails,
> domains, IPs, malware, card numbers, UPI ids, bank accounts and Bitcoin addresses were
> generated by the scripts in [`analysis/scripts/`](analysis/scripts) for a college assignment.
> No real person, company, server or wallet was contacted, harmed or defrauded. Do **not**
> connect any IP, domain or account listed here.

## 🚀 Setup instructions

**Requirements:** Python **3.11+** (standard library only — *zero pip installs*).

```bash
# 1. clone
git clone https://github.com/normienishant/Operation-Hydra.git
cd Operation-Hydra

# 2. run the full analysis suite (builds evidence, runs all six investigation steps)
python analysis/scripts/run_all.py

# 3. build the DOCX/PDF deliverable (needs python-docx + fpdf2)
pip install python-docx fpdf2
python builder/build_report.py
```

Every script is also runnable standalone — each one `--help`s:

| # | Command | Purpose |
|---|---------|---------|
| 1 | `python analysis/scripts/generate_phishing.py` | Regenerate the 5 synthetic `.eml` samples |
| 2 | `python analysis/scripts/analyze_headers.py` | Parse all e-mail headers: Received chain, SPF/DKIM/DMARC verdicts, URL extraction |
| 3 | `python analysis/scripts/ip_trace.py` | Geolocate/abuse-score attacker IPs via AbuseIPDB-style logic, print trace report |
| 4 | `python analysis/scripts/whois_lookup.py` | Offline WHOIS registrar/age comparison for the forged domains |
| 5 | `python analysis/scripts/malware_decoder.py` | Base64/XOR-decode the specimen, classify it, emit IOCs |
| 6 | `python analysis/scripts/trace_funds.py` | Follow the money: link transactions → mule accounts → BTC wallet |
| 7 | `python analysis/scripts/generate_transactions.py` | Regenerate the synthetic transaction CSV |
| 8 | `python analysis/scripts/run_all.py` | Orchestrator — runs 1–6, writes every log in `analysis/logs/` |

## 🗺️ The case in one paragraph

On **14 March 2026**, 212 employees of the fictional **Aurora Logistics Pvt. Ltd.** received a
pilot-leave e-mail spoofing HR. 68 clicked; 41 submitted credentials on `aurora-hrportal.net`
(a 6-day-old domain spoofing `auroralogistics.in`). 17 machines were infected by
`INVOICE_MAR2026.pdf.xlsm`, which implanted **HydraRAT** (RAT + keylogger + logic-bomb
components). Stolen card/UPI data was drained via ~₹6.2 lakh in micro-transactions to four
mule accounts, then cashed out to BTC wallet `bc1qhydra9f2...mule7`. Six distinct offences and
the money trail are reconstructed here. Full narrative: [`docs/case_brief.md`](docs/case_brief.md).
